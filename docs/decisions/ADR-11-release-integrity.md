# ADR-11 数据完成状态与发布完整性

日期：2026-11-12。状态：接受。更正 decisions.md 中 ADR-02 的月度端点说明及 ADR-07 的九门禁列表。

日线最大日期不代表数据完整。每个数据日事务写入、验质，失败回滚；逐数据集完成状态独立保存，允许同日重试。近20个交易日重查，历史日线缺口、降级日期和迟到可选数据另行回补。没有权限的数据保持缺失，不伪造0或其他指标。

完整发布统一调用 pipeline.release。操作系统持有锁覆盖拉取、验质、重建与导出；进程退出自动释放，不按30分钟猜测锁过期。所有marts在同一事务重建，单文件HTML临时写完后原子替换。失败保留上次HTML，成功发布后清告警。API可能在core提交与mart重建间仍读取旧完整mart；不承诺数据库与HTML跨文件同时切换。

选择按市场交易日严格连续：停牌/漏日打断价格连板；CW仅取上一市场交易日市值，缺失则退出加权。IPO年龄按上市日和日历，与已加载历史长度分离。MA仍按有效观察窗口。

市场/行业月累计为每日EW复利；月表ew_ret为日均值，不能当月收益继续复利。指数缺日不补0。十四门禁的阈值与分级以 quality_gates.py 和 technical.md 为准。

历史ST身份不可从当前名称重建。旧ST涨停字段保留字段形状但返回NULL，新增明确幅度名称；不宣称已经获得真实历史ST统计。

第二阶段已修改前端金额、持仓收益、简报、图形和静态查询差异，并在副本回补历史数据。范围与剩余数据源限制以 release_completion_report.md 为准；不将门禁通过等同于上游数据已获独立认证。
