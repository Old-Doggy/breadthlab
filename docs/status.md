## 6. 与规格的偏离（已在 `docs/decisions.md` 记录）

1. **FastAPI → Flask**：沙箱内 asyncio 不可用。
2. **Playwright → 无头 Edge**：同上，且中文路径需 ASCII 临时文件。
3. **北向**：口径断裂，剔除时间序列。
4. **行业映射**：静态桥接而非 PIT（`index_member_all` 无权限）。
5. **连板**：`limit_list_d` 无权限，改价格判定 + 连续天数。
6. **静态单文件导出**：为离线/无服务器场景新增，规格未要求。
