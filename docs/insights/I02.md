# I02 · 涨幅集中在少数股票

**问题**：指数的涨跌，有多少由少数权重股贡献？

**口径**：`top10_share = Σ_{Top10权重}|w·r| / Σ|w·r|`（有界 0–1）；`gain_share_top5pct` 为涨幅前 5% 股票的正收益份额。

**证据**：Top10 权重股贡献了当日波动的一半以上的天数：**34 天**（1.6%）；全样本均值 12.7%。

| trade_date | top10_share | gain_share_top5pct | ew_ret |
|---|---|---|---|
| 2018-07-02 | 80.5% | 58.3% | -1.20% |
| 2018-09-28 | 77.0% | 25.7% | +1.01% |
| 2018-01-30 | 76.9% | 44.5% | -0.27% |


**图表位置**：Market 页集中度副图（20 日均值 + 日值浅柱）；Today 页 Top10 贡献 KPI。

**边界**：Top10 由前一日流通市值决定；权重股横盘时该指标会偏低，需与广度一起读。
