# I08 · 轮动强度刻画行情性质

**问题**：行业排名迁移速度，能否区分单边行情与快速轮动？

**口径**：`rotation_intensity_t = mean_i |rank_{i,t} − rank_{i,t−1}|`，排名按 20 日累计收益。

**证据**：2018 年以来轮动强度均值 **2.32 名/日**，95 分位 3.87；最高 6.77。

| trade_date | rotation |
|---|---|
| 2025-05-08 | 6.77 |
| 2026-09-04 | 6.45 |
| 2019-11-25 | 6.19 |


**图表位置**：Sectors 页轮动视图（规划中）；当前可用行业热力图观察轮动。

**边界**：排名基于 20 日窗口，窗口选择会改变强度绝对值；只做相对比较。
